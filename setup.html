Job Tracker setup

This creates the login for your tracker. Everything happens in this browser: your token is encrypted with your password before it leaves this page, and this page can only talk to api.github.com.

1. Create a GitHub access token

  1. Signed in as the account that owns the private jobs repo, open GitHub → New fine-grained token.
  2. Name it Job Tracker and pick an expiration (you'll redo this setup when it expires).
  3. Repository access: Only select repositories → choose the private jobs repo.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate the token and paste it below.

2. Fill in your login

Your login
Private jobs repo

3. Publish the login file

Download config.enc.json and put it next to index.html in the public site repo (or send it to Claude to commit). It's encrypted — useless without your username and password.
